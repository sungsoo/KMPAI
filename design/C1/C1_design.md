# C1 설계: 다관절 팔에서의 제약 보존 보정과 승인 검정 (잠금, 2026-11-06)

## 1. 왜 이 실험인가
B13 결정(2026-11-06): manuscript-v1을 Technovation 원고와 분명히 다른 연구로 만들기 위해, **C1을 이 원고의 주된 증거**로 삼고 2자유도 80 실행 결과는 Technovation 원고(심사 중)를 인용하는 한 문단 요약으로 줄인다. 그래서 C1은 연구 질문, 데이터, 결론이 모두 새것이어야 한다.

## 2. 다른 원고와의 경계
| 원고 | 다루는 것 | C1에서 피하는 것 |
|---|---|---|
| Technovation 원고 | 2자유도 진동계, 마일스톤 / 관문 설계, 정책 문서 분석 | 2자유도 데이터 재사용, 정책 / 관리 결론 |
| IFusion(T1) | 휴머노이드 제어기의 **마모 중 사용 승인 재검정**(시간에 따른 재인증, 증거 융합) | 마모 / 감쇠 증가 이동, 재검정 일정, 제어기 승인 |
| IFGraph | 관절 **마모 위치 판정**(GNN, 등각 위치 집합) | 마모 위치, 그래프 모델 |
| **C1(이 원고)** | **월드모델 예측 보정의 자유도 확장**: 관절 수가 늘 때 제약 보존 보정의 위험, 승인 검정의 분포 내 보장, 관절 간 결합(전체 행렬)의 효용, 필요한 판정 표본 수 | — |

기본안에서 분포 이동은 **작업 범위 확대(range widening)만** 둔다(마모 / 감쇠 이동은 IFusion과 겹치므로 제외, 결정 대기).

## 3. 연구 질문과 사전 고정 주장 (plan.toml)
| 주장 | 내용 | 기준(min_effect) | 반증 조건 |
|---|---|---|---|
| M1 | 항상 적용하는 수축 보정이 범위 확대에서 keep_Z보다 나쁜 실행이 각 시스템에서 10% 이상 | 0.10 | 단측 95% 상한 < 0.10이면 그 시스템에서 미지지 |
| M2 | LTT가 승인한 실행 중 분포 내 악화 비율이 각 시스템에서 δ = 0.1 이하 | 0.10(명제 2의 δ) | 단측 95% 하한 > 0.10이면 미지지, 승인 10개 미만이면 판단 보류 |
| M3 | 7자유도에서 LTT의 실행별 상대 이득 중앙값(기각은 0) ≥ 5% | 0.05 | 부트스트랩 95% 구간 하단 < 0.05이면 미지지 |
| M4 | 7자유도에서 전체 행렬 후보가 대각 전용 대비 중앙값 이득을 5%p 이상 높임 | 0.05 | Holm 보정 p ≥ 0.05 또는 차이 < 0.05이면 미지지 |
| M5 | (서술) 자유도에 따른 전체 행렬 선택 비율, 판정 표본 n = 36 / 60 / 100별 승인율 | — | 판정 없음 |

기대값은 모두 "기대(결과 아님)"로만 적었다.

## 4. 시스템, 데이터, 방법
- **시스템(기본안):** 평면 2관절 팔, 평면 3관절 팔(직접 구현한 강체 동역학), Franka Emika Panda 7자유도(MuJoCo + MuJoCo Menagerie 모델, 커밋 고정). 물리 사전 지식 = 공칭 모델, 실제 = 관절 마찰(쿨롱 + 점성), 링크 질량 오차, 관절 결합 추가. 학습 월드모델 Z = 잔차 MLP(폭은 d에 비례). 2자유도는 Technovation의 진동계가 아니라 새 평면 팔이다.
- **분할(실행마다):** 학습 12 / 36, C_f 12, C_s1 12, C_s2 36(사후 60 / 100), 시험 48 에피소드. 시험 데이터는 별도 seed로 생성.
- **설정:** 시스템 3 × 학습 크기 2 × 라벨 잡음 2 × seed 34 = 408 케이스(케이스마다 모든 방법 계산).
- **방법:** 제안 ltt_correction(알고리즘 1 그대로) / 강한 비교군: 동일 예산 재학습, 평균 손실 규칙, 단계별 결합 / 단순 비교군: keep_Z, 물리 사전 지식 / 제거 실험: 수축 없음, 승인 검정 없음(고정 행렬), 전체 행렬 후보 없음(대각 전용).
- **공정성:** 테스트 분할로 조정하지 않음. 모든 보정 방법이 같은 λ 격자와 같은 C_s1을 쓴다.

## 5. 통계, seed, 예산
- 실행 단위 대응 비교, Wilcoxon, Holm 보정(M1~M4), 비율은 Clopper-Pearson, 이득은 seed 군집 부트스트랩 95%.
- seed 34개: 2자유도 파일럿의 seed 간 표준편차(이득 0.079, 범위 확대 악화 비율 0.162)로 M1 / M3 / M4의 검정력 0.8에 필요한 수(33~34). M2(정의상 표준편차 0)와 M5(서술)는 추정 대상이 아니다.
- 예산: plan_tool 추정 약 190분(방법 × 실행 기준). 주 실행은 Mac(병렬), Linux 샌드박스는 축소 점검과 교차 플랫폼 결정 검사(결정 대기).
- 중단 규칙: 예산 80% 초과 시 seed가 아니라 Franka의 학습 크기 설정 하나를 줄이고 기록, 실패 실행은 결측으로 기록.
- plan_tool check: 오류 0 / 경고 3(M2·M5 표준편차 없음은 설계상 정상, 합성 데이터 명시 의무).

## 8. 판정 규칙 보완과 가시화 (2026-11-06, 주 실행 데이터 전)
- 가시화 실행기를 축소 점검 결과에 시험하다가, M1과 M2의 잠금 규칙이 "지지"의 조건을 정하지 않아 근거가 없는 경우(예: 2실행 중 악화 0)도 "지지"로 판정되는 문제를 찾았다. 주 실행 전이므로 계획서를 사유와 함께 다시 잠갔다(plan_changes.md, 해시 1527aee13baf → c209be719897): M1은 단측 95% 하한 ≥ 0.10이면 지지, 상한 < 0.10이면 미지지, 그 밖은 판단 보류; M2는 승인 10개 미만 또는 구간이 0.10을 걸치면 판단 보류, 상한 ≤ 0.10이면 지지, 하한 > 0.10이면 미지지. 기준값과 데이터는 바뀌지 않았다. 실행기 잠금도 새로 만들었다.
- 가시화: `impl/c1/c1_viz.py` + 규칙 `viz_rules.json`(잠금 viz_rules_lock.json, 주 실행 결과 전). 그림은 claims.json의 판정을 그대로 표시하고 결과 파일에서 다시 센 값과 같은지 검사한다. 장면은 중앙값 규칙으로만 고르고, 재생하는 궤적을 다시 계산해 저장된 MSE와 일치하는지 검사한다.
